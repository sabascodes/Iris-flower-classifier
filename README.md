# Iris Flower Classifier 🌸

A simple machine learning project that uses the K-Nearest Neighbors (KNN) algorithm to classify Iris flowers into three species: Setosa, Versicolor, and Virginica, based on their measurements.

## About the Project

The project includes data exploration, visualization, model training, evaluation, and hyperparameter tuning.

## Technologies Used

- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Joblib
- **Development Environment:** Google Colab

Results

* Algorithm: K-Nearest Neighbors (KNN)
* Best K: 5
* Test Accuracy: 100%
* Cross-Validation: Used for hyperparameter tuning
